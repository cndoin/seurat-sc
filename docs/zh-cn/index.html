围绕真实 API 设计

Agent 指令、机器可读 API 目录和本地静态检查器协同工作。

01 / 检查

交付前检查 R 脚本

识别不存在的函数、不支持或已弃用的参数、括号引号错误和常见全角标点。

02 / 查询

搜索真实函数签名

离线查询导出符号及提取出的参数，不必把分析代码或数据发送到外部服务。

03 / 规划

推荐常见分析流程

为 QC、SCT、整合、映射、空间分析、WNN 等任务提供确定性的起始步骤。

几条命令即可安装

需要 Python 3.7+；Python 侧无需第三方依赖。

终端
git clone https://github.com/cndoin/seurat-sc.git
cd seurat-sc
python3 install.py
python3 tools/selftest.py

安装到 Codex 或其他 Agent 时，使用 python3 install.py --dir <skills目录> 指向宿主的技能目录。安装后重启宿主以加载技能。

给 AI Agent 的说明

  1. 以 SKILL.md 作为技能入口加载。
  2. 保持包内目录结构，工具和参考资料使用相对路径。
  3. 交付 R 脚本前运行 python3 tools/sc_lint.py analysis.R --json。
  4. 解决 lint 错误，并说明警告与运行环境限制。
  5. 不要臆造样本路径、物种、细胞标签或分析结果。

工具能力与边界

sc_lint.py

R 静态检查

不需要安装 R；依据随包 API 快照校验，但不能证明脚本可运行或分析结论可靠。

sc_api.py

离线 API 查询

搜索 Seurat / SeuratObject 函数签名和模块分类。

sc_plan.py

分析流程建议

基于规则给出建议起始步骤，不能替代研究设计或生物学判断。
