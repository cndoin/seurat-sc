Instalación rápida

Python 3.7 o posterior; no requiere paquetes Python adicionales.

git clone https://github.com/<OWNER>/seurat-sc.git
cd seurat-sc
python3 install.py
python3 tools/selftest.py

Para Codex u otro host, indica la carpeta de skills con python3 install.py --dir <skills-directory>. Reinicia el host después de instalar.

Instrucciones para agentes

  1. Carga SKILL.md como punto de entrada.
  2. Conserva la estructura para que funcionen las rutas relativas.
  3. Antes de entregar un script R, ejecuta python3 tools/sc_lint.py analysis.R --json.
  4. Resuelve los errores y comunica advertencias y límites del entorno.
  5. No inventes rutas, organismos, etiquetas celulares ni resultados.

Funciones y límites claros

sc_lint.py

Revisión estática de R

No necesita R. Comprueba frente a una instantánea API; no garantiza ejecución ni validez científica.

sc_api.py

Referencia sin conexión

Busca firmas y categorías de Seurat / SeuratObject.

sc_plan.py

Sugerencias de flujo

Ofrece un punto de partida determinista, no sustituye el diseño del estudio.
