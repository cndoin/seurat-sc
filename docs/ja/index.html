オフラインツールPython 標準ライブラリSeurat 5.xWindows · macOS · Linux

実在する API に基づく設計

簡潔なエージェント指示、機械可読な API カタログ、ローカルの静的チェッカーを組み合わせています。

01 / CHECK

提出前に lint

存在しない関数、未対応・非推奨の引数、括弧の不整合、全角記号を検出します。

02 / SEARCH

実際のシグネチャを検索

解析コードやデータを外部へ送らず、エクスポートされたシンボルと引数をオフライン検索できます。

03 / PLAN

一般的な解析フローを提案

QC、SCT、統合、マッピング、空間解析、WNN などの開始手順をルールベースで示します。

簡単にインストール

Python 3.7 以降が必要です。追加パッケージは不要です。

git clone https://github.com/<OWNER>/seurat-sc.git
cd seurat-sc
python3 install.py
python3 tools/selftest.py

Codex などでは python3 install.py --dir <skills-directory> でスキルフォルダーを指定します。インストール後、ホストを再起動してください。

AI エージェント向け

  1. SKILL.md を入口として読み込みます。
  2. 相対パスを保つため、パッケージの構成を維持します。
  3. R スクリプトを返す前に python3 tools/sc_lint.py analysis.R --json を実行します。
  4. lint エラーを解消し、警告と環境上の制約を説明します。
  5. サンプルパス、生物種、細胞ラベル、結果を推測で作りません。

機能と制約

sc_lint.py

R の静的チェック

R は不要です。API スナップショットの検査であり、実行成功や科学的妥当性を保証しません。

sc_api.py

オフライン API 検索

Seurat / SeuratObject のシグネチャと分類を検索します。

sc_plan.py

解析フローの提案

ルールベースの出発点を提示します。研究デザインの代替ではありません。

バージョンと帰属

本リリースの API カタログは Seurat 5.5.1.9005、SeuratObject 5.0.2 を基に生成されています。異なるバージョンでは実環境を確認してください。本プロジェクトは独立しており、Satija Lab の公式プロジェクトではありません。NOTICE · MIT ライセンス
