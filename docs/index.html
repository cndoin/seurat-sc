Install in a few commands

Python 3.7+; no third-party Python packages.

Terminal
git clone https://github.com/<OWNER>/seurat-sc.git
cd seurat-sc
python3 install.py
python3 tools/selftest.py

For Codex or another host, use python3 install.py --dir <skills-directory> to select its skills folder. Restart the host after installation.

For AI agents

  1. Load SKILL.md as the entry point.
  2. Keep the package directory intact; references and tools use relative paths.
  3. Before returning an R script, run python3 tools/sc_lint.py analysis.R --json.
  4. Resolve lint errors, then explain warnings and environment limits.
  5. Never invent sample paths, organism, cell labels, or result values.

Useful tools, clear boundaries

sc_lint.py

Static R checks

No R installation required. It checks against the bundled API snapshot; it does not prove an analysis executes or is scientifically valid.

sc_api.py

Offline API lookup

Search function signatures and module groupings in the Seurat / SeuratObject catalog.

sc_plan.py

Workflow suggestions

Rule-based recommendations offer a starting point, not a substitute for study design.
