## Coverage limits

This review validates the shipped tools, installation, runtime protocol, packaging, offline catalog rebuild, and one actual Seurat workflow. It does not run all 406 catalog symbols or every spatial, SCT, integration, WNN, mapping, and third-party workflow with representative datasets. Optional package availability is reported by preflight; absence of an optional package does not make the offline tools unusable. The online download path's live network behavior is not certified by the offline rebuild test.
